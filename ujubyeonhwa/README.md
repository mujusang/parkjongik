# 우주변화의 원리 — 전권 정리

한동석 『우주변화의 원리』(대원출판, 2001, ISBN 89-7261-055-0)를 472쪽 전체로 읽고 장·절마다 정리한 읽기·검색 페이지입니다.

## 담긴 것

- 머리말·서론과 전편 법칙편 1~4장, 후편 변화론 5~9장, 부록(저자 소개·발간사·색인 안내)
- 장마다 핵심 논지, 절별 요점, 쪽수를 붙인 원문 인용, 핵심 한자·용어 해설, 도표 해설
- 용어 사전, 장·절 목차 이동, 키워드·한자·쪽수 실시간 검색

## 쓰는 법

- 검색창에 낱말이나 한자를 넣으면 정리 본문과 용어 사전에서 바로 찾습니다.
- 숫자만 넣으면 그 쪽이 실린 절을 찾습니다. 예: `118`
- 휴대폰에서는 왼쪽 위 ☰ 단추로 목차를 엽니다.

정리 본문은 마크다운 원본(`../summary/`)에서 만들어집니다.
